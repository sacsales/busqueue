# Busqueue 
- A prototype digital queuing system for a public transit hub in Manila, focusing on the Point to Point (P2P) bus system. 
- Bus terminals at One Ayala are super crowded and humid from bus exhaust. Long lines are chaotic and unpleasant.
- Users can reserve a spot on the next bus + receive a push notification 15 before their bus arrives so they can wait indoors instead of lining downstairs


- Frontend: HTML, CSS and JavaScript 
- Database & Backend: Node.js + Express, PostgreSQL, Neon, Render
